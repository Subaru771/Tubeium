# Tubeium 1.02 — Windows v1.0.6

**Stable Windows x64 update · November 3, 2026**

Tubeium 1.02 is the public-facing name for the internally versioned **v1.0.6** build. Earlier GitHub tags (including v1.0.2) are preserved rather than reused.

## What's new

- **Ad-skipping initialization repaired.** Fixed a local-module import that could abort the YouTube preload in Electron's secure sandbox, preventing the existing best-effort ad filters and skip fallback from starting.
- **Settings are visible again.** Replaced the small faded gear with a high-contrast, labeled Settings control positioned above Tubeium's bottom bar.
- **Refreshed Tubeium navigation.** Modernized the bottom navigation style and added a Settings entry point that's still accessible with the Sign-in Help tabs collapsed.
- **Reliability improvements.** Restore the floating Settings shortcut after YouTube single-page navigation, and check sandbox startup and navigation behavior in regression tests.
- **No forced data reset.** Existing preferences and local data remain in their normal application locations.

## Testing and limitations

Automated source tests, dependency audits, packaging verification and SHA-256 checks must pass before publication. A successful build does not prove every YouTube video or Google sign-in flow works on a real Windows device. Ad filtering is **best-effort**: YouTube can change its delivery and playback behavior. No guarantee of an entirely ad-free experience.

**Unsigned executables:** Windows SmartScreen may warn. Download only from this repository, validate SHA-256 checksums if needed, and do not disable antivirus protections globally.

Tubeium is an unofficial YouTube client and is not endorsed by Google or YouTube.
