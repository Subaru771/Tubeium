# Tubeium v1.0.13 — Phone gestures and lower background overhead

**Windows x64 · unsigned installer and portable EXE**

## Touchscreen gestures

- **Double-tap** the left or right side of a playing video to seek −10 or +10 seconds. Honors the *Disable YouTube double-tap seek* preference.
- **Swipe** left/right over a normal YouTube video for Next/Previous, using existing bounded navigation and playlist controls.
- **Swipe** up/down over Shorts for the next/previous Short using native Shorts navigation.
- **Pinch** with two fingers over the video to zoom from 1× to 3×. Pinch back in or navigate to reset. Zoom affects only the video, not the whole page.
- Tubeium reflows its controls when a Windows touchscreen device rotates; **Windows controls physical screen rotation and rotation lock**.
- Mouse, keyboard, pen, normal player buttons and timeline remain separate from these touch-only gestures.

## Memory and background activity

- Allow Electron/Chromium to throttle hidden-window UI timers rather than keeping the YouTube renderer artificially active while minimized or in the tray.
- Release the local Sign-in Help rendering view after switching back to YouTube, while preserving the main-process browser pairing service until it completes.
- Skip periodic video-card scanning, smart-profile checks, player-quality UI updates and DOM restoration while hidden, restoring on return.

These changes reduce unnecessary background renderer activity and can reclaim an unused Help renderer, but **no specific MB or percentage RAM saving is guaranteed or measured**. YouTube's video decoding, Chromium renderer processes and loaded content continue to consume memory. For a fair comparison, open the same video and quality in each release and compare **System Diagnostics → memoryWorkingSetMB / electronProcesses**.

## Verification and limitations

[PR #27](https://github.com/Subaru771/Tubeium/pull/27) passed all 59 source test files, including simulated swipe, seek and pinch gestures. The release pipeline independently verifies dependency integrity, tests, audit, Windows installer, portable EXE and SHA-256 checksums before publication.

**Real Windows touchscreen testing is still needed**, including YouTube updates, Google sign-in, physical rotation, pinch behavior, Bluetooth/headphone controls, minimized playback and actual memory measurement. Tubeium remains a Windows desktop application, **not a native Android/iOS app**.

**Unsigned executables:** Windows SmartScreen may warn. Download only from the official GitHub Releases page and verify the published checksums.
