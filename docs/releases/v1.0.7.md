# Tubeium 1.07 — Windows v1.0.7

**Windows x64 release · November 8, 2026**

Tubeium 1.07 expands the Settings and playback experience while preserving existing local preferences and the original YouTube client.

## What's new

- **Favorite Settings:** pin up to 24 frequently used options with the star on any Settings row. A new **Favorites** section and an Overview shortcut give you a focused home for those controls. Pins are stored locally in a validated user-data file and do not duplicate or reset the underlying settings.
- **Playback Diagnostics:** open the **Stats** button on the floating YouTube toolbar, or select **Player → Playback Diagnostics**. Inspect decoded resolution, estimated rendered FPS, dropped-frame percentage, buffered-ahead seconds and playback status. **Copy diagnostics** generates a report without account cookies, tokens or the current video URL.
- **Independent Settings resizing:** drag the sidebar's right edge to change its width, and drag the horizontal divider above Live Customization to adjust the lower quick-action panel's height. Both sizes are remembered; keyboard controls and double-click reset are supported.
- **Smaller lower-sidebar controls:** compact the quick-action icons and buttons for a cleaner interface.
- **Working update checks:** check the official GitHub Releases endpoint for unsigned public updates, with an explicit choice to open the release page. No automatic download or installation of unsigned EXEs.
- **Up to 4K status:** Tubeium's floating Quality control displays the currently decoded stream resolution, including 4K when actually reported; clicking it opens YouTube's native quality selector. The quality preference does not force 4K availability.
- **Reliability regression tests:** preserve the Electron sandbox, existing 201 validated preferences, navigation, and local sign-in data. Add regression checks for favorites, live statistics, new controls, sidebar sizing, release updates and stream-resolution labels.

## Known limitations

- Google can block third-party or embedded sign-in; no particular sign-in method is guaranteed.
- YouTube ad skipping is best-effort; YouTube changes can break it. Disable it in Settings if playback is unstable.
- Stream-resolution information and frame statistics depend on what the Chromium video element exposes; estimated FPS is not the source framerate.
- Live Google sign-in, ad delivery and individual 4K videos have not been verified by automated CI. A successful Windows build is not proof of those external behaviors.
- The applications remain **unsigned**. Windows SmartScreen may display a publisher warning. Only download from the official Tubeium repository and use the checksum file if verification is needed. Don't turn off Windows protection globally.
