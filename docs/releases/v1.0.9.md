# Tubeium 1.09 — Windows v1.0.9

**Windows x64 patch release · November 8, 2026**

A small, focused improvement to downloading and the bottom-right shortcuts.

## Download is now one action

- **Download video** queues only the current video. It no longer toggles a download menu or opens the manager.
- **⌄ More options** opens the format and playlist menu only.
- **Open download manager** opens the manager only when that entry is explicitly chosen.
- Click handlers prevent accidental propagation into the underlying YouTube page. Errors are still reported without automatically opening extra windows.

## Two optional bottom-right buttons

- The floating **Download video** button and **Have a problem signing in?** button sit together in the bottom-right corner above Tubeium's tab strip.
- In **Settings → Downloads → Bottom-right shortcuts**, independently turn **Show floating Download button** and **Show sign-in help shortcut** on or off.
- Old left-side Download placement is removed, including from existing saved settings. The bottom-left **Settings** control remains available.
- **Have a problem signing in?** opens the existing local Sign-in Help tab rather than launching a sign-in/import workflow without explanation.
- The Download button appears only on video pages. Sign-in help is available across YouTube. Both are hidden during fullscreen and mini-player mode.

## Compatibility and safety

Preserves all existing downloads, queue jobs, user settings, secure IPC boundaries and account/session data. The 201-setting catalog remains the same size, with the retired left/right placement option replaced by the new sign-in help visibility toggle.
