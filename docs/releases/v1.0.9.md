# Tubeium 1.09 — Windows release notes (v1.0.9)

**Verification:** The source regression suite passed (48/48 test files), and the Windows x64 installer and portable EXE were packaged successfully with SHA-256 checks on November 9, 2026. The app is unsigned; Windows SmartScreen may display a warning. Live YouTube behavior and Google sign-in have not been independently verified on a Windows PC.

## Cleaner YouTube interface

- A single native **◈ Tubeium** button replaces the floating Settings button and the old two-pill bottom-right Settings / Show tabs controls.
- Its compact menu offers **YouTube**, **Settings** (`Ctrl+,`), **Download Manager**, **local Watch Later**, **Sign-in Help**, and an optional full navigation bar.
- **Sign-in Help** appears in one Tubeium menu only. The extra sign-in prompt over the video and recommendations has been removed; the Help menu item remains independently hideable.
- **Download** attaches to a usable watch action row, and otherwise remains visible near the active video rather than disappearing until hover. Shorts and live videos use this fallback; Tubeium rebuilds the button if YouTube removes it during navigation.
- Extra playback tools are located relative to the real video player and appear on hover or keyboard focus. They no longer sit permanently over the recommendations column.
- The full-width bottom navigation bar is opt-in for new users; earlier saved preferences remain respected.
- A separate Download click queues the video, the adjacent chevron opens formats, and Download Manager opens only on explicit request. All existing download settings and queue data are preserved.

## Download or Watch Later without opening a video

Home-feed thumbnails, supported search results, and recommendations now show compact **↓ Download** and **◷ Watch Later** quick actions continuously, including when a thumbnail hover preview starts playing. These controls no longer depend on YouTube's transient hover state. Clicking either button does not open the video. The watch page/player has a dedicated Watch Later button beside Download; both work on Shorts and live pages where a video ID is available.

Watch Later saves to **Tubeium Local Library → Watch Later**, available directly from the Tubeium menu. Saves are immediate, persist across app restarts, remain after clearing passive watch history, and can be removed in the Library. **This is not YouTube's account-synced Watch Later playlist:** it works without Google sign-in and no silent authenticated YouTube action is performed.

## Rebuilt Download Manager

The manager is now a compact queue, not a large dashboard. Every item shows the title, channel when available, requested quality/format, a confirmed selected resolution when yt-dlp reports it, a progress bar and its current speed or ETA. Finished items offer Play and Show File; active/paused/failed items offer Pause, Resume or Retry, with secondary commands under a single menu.

New downloads immediately display the **requested limit** (e.g. *Up to 1080p · MP4*). It does not imply the source offers that resolution. Tubeium uses the current YouTube page title when available, checks YouTube's public metadata endpoint without cookies for pasted URLs, and updates with yt-dlp's actual selected video height. If the network lookup fails, the queued item still proceeds.

## Settings and compatibility

Settings opens directly into **six focused everyday categories**: General, Appearance, Playback, Downloads, Privacy & Ads, and Library & Keys. The dashboard, presets, favorites panel, extra resize handle, duplicate navigation and visual clutter are gone. Import/export, backups, update checks and destructive maintenance are grouped in a small overflow menu. **Advanced** is always available as the final sidebar tab. Its seven topics—Player & Audio, Appearance & Feed, Download Details, Privacy & Blocking, Shortcuts & Devices, Local Library, and Windows & Tools—show only less-used preferences, with no duplicates of everyday Settings. All 201 underlying preferences, saved values and local app data remain intact.

The optional **Show Tubeium launcher** and **Sign-in Help in Tubeium menu** settings control the native interface. The sign-in recovery instructions are not a second automatic sign-in attempt. YouTube's native account sign-in remains unchanged.

## Verification

GitHub's source regression checks cover Download, local Watch Later, settings, and thumbnail hover-preview replacement. The app uses Electron's sandboxed preloads and trusted native IPC. The Windows build and dependency audit passed; hands-on playback/sign-in tests are still necessary. Automated tests cannot guarantee that YouTube's changing website layout will always expose its action row.
