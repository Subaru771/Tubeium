# Tubeium 1.09 — Windows v1.0.9

**Windows x64 · November 8, 2026**

This release fixes the Download button and replaces the previous Settings interface with a genuinely new compact application workspace.

## A rebuilt Studio, not a reskin

- New **three-area Settings layout**: resizable category navigation, a central preferences workspace, and an always-useful control inspector (when window width permits).
- No large promotional header: compact summary, live six-switch controls, quick category links, presets and starred settings.
- Individual setting sections collapse/expand. Each row shows useful descriptions and whether it was modified from its default.
- Search all settings with **Ctrl+K**, or filter the current category; light and dark themes share the same consistent design system.
- Preserve 201 existing settings, local data, import/export, favorites, the existing two independent resize handles, and video playback diagnostics.

## The Download button works the way it should

- **Download video:** one click queues the current video. It does **not** open the options menu or the download manager.
- **Chevron (⌄):** choose video/audio/thumbnail/playlist actions.
- **Download manager:** opens only when explicitly requested from the menu or app shortcuts.
- Floating actions live in one **right-side dock**, clear of the native bottom navigation bar.
- A separate **Having trouble signing in?** button is next to Download, opening the existing help guide.
- Each floating button has its own × dismissal, which persists as a setting. Restore either in Settings → Downloads. The old left/right Download position option has been retired.

## Compatibility

The app preserves its existing browser profile and local media/library data. The obsolete download-position preference is ignored rather than allowing a hidden left-side button to reappear.

Google sign-in, ad skipping, and external YouTube media extraction can change without notice. CI tests and Windows packaging cannot establish compatibility with every real YouTube video or account. The Windows executables are unsigned and may show a SmartScreen warning; do not globally disable security software.
