# Tubeium 1.09 — Unreleased source (v1.0.9)

**Status: development branch / Windows binary not yet published or verified.**

Tubeium 1.09 repairs the Download interaction and replaces the Settings interface with a compact, task-first layout. It is not the same as the public 1.08 installer.

## One click means one download

- **Download video** queues the current video's download; it does not open a menu or Download Manager.
- **⌄ More** opens the video, audio, thumbnail and playlist choices without initiating a download.
- **Open Download Manager** is a separate explicit command in the menu and in Settings.
- Separate event handlers stop clicks from cascading into the surrounding page or other Tubeium controls.
- The redundant Download Manager shortcut in the floating player toolbar is removed.

## Right-side controls

The **Download video** and **Have a problem signing in?** buttons use a single dock at the **bottom-right** of YouTube. Each has an independent visibility toggle in **Settings → Downloads**, and both can be hidden. No bottom-left Download control is created, and older saved left-placement preferences have no effect. The bottom-left **Settings** shortcut is a different control and remains available.

The Download button appears on watch pages, while sign-in help is accessible across YouTube. Both are hidden in fullscreen and mini-player modes. Sign-in help opens the existing local help tab; it does not silently change account data.

## Settings rebuilt from scratch

The former large promotional homepage and permanent inspector column have been replaced. The new interface has:

- A compact, resizeable navigation sidebar with a separate adjustable shortcuts section.
- A lightweight top bar with category breadcrumbs, global search, Download Manager, font sizing, and import/export.
- Two-column workspace cards for everyday switches and a live preview of the two right-side player actions.
- Slim profile presets, a category grid, and favorite setting shortcuts.
- Compact, collapsible **two-column** category panels rather than one endless list.
- Dark/light modes, keyboard focus indicators, and reduced-motion support.

The existing 201 preferences, favorites, download queue, playback diagnostics, local library, login flows, and security boundaries remain in place. The UI is a rewrite of the presentation, not a reset of saved settings.

## Verification and limitations

Focused simulated event checks confirm that clicking Download queues only a video, clicking More only opens the menu, and the Manager and sign-in help respond to their own controls. A fake-DOM smoke check confirms that the 201-setting schema boots, all 15 categories are navigable, and the two visibility settings are rendered.

**Full GitHub Actions jobs are failing before test steps execute**, so neither the full suite nor a Windows build has been verified through CI. No 1.09 installer, portable EXE or checksum file is currently published. A real Windows playback and sign-in test is still required before release.

Until then, use the [latest verified public release (1.08)](https://github.com/Subaru771/Tubeium/releases/tag/v1.0.8).
