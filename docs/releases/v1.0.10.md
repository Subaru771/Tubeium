# Tubeium v1.0.10 — download and local-library reliability

**Windows x64 · unsigned installer and portable EXE**

This update includes [merged PR #23](https://github.com/Subaru771/Tubeium/pull/23) on top of the v1.0.9 design update.

## Fixed

- Prevent duplicate yt-dlp processes when pausing and resuming a download; ignore stale events from previous attempts.
- Resume processing queued downloads restored after a restart, and prevent new jobs from launching during shutdown.
- Save each download's requested format and quality with its job so later Settings changes do not silently change the queue.
- Respect the requested maximum resolution through **all** format fallbacks. A source without an eligible format now fails explicitly instead of exceeding the limit.
- Replace unsupported Electron prompt calls with accessible create, rename, and add-to-playlist dialogs, including cancellation and input validation.
- Merge imported Watch Later and bookmark status without losing newer playback metadata.
- Validate playlist names before changing local library data.

## What's included from v1.0.9

Compact Tubeium launcher and Settings, streamlined Download Manager, player download actions, and local Watch Later from video cards and player pages.

## Verification and limitations

PR #23 passed its 53-file source regression suite, a release audit, Chromium playlist UI checks, and yt-dlp resolution fallback tests. The release workflow independently checks the committed dependency lockfile, executes tests and an audit, then builds Windows setup/portable packages and generates SHA-256 checksums before publication.

**Windows live playback, real YouTube downloads and Google sign-in have not been independently acceptance-tested.** Some website-dependent controls may need updates as YouTube changes. The Windows binaries are **unsigned**; SmartScreen may warn. Download only from this project's official GitHub Releases page and verify checksums.
