# Tubeium 1.08 — Windows v1.0.8

**Windows x64 release · November 8, 2026**

Tubeium 1.08 focuses on a redesigned Settings experience, easier one-click downloading, and finally retiring the legacy uYouPlus download folder name.

## New Control Room

- Complete visual redesign of the Settings window, with refreshed typography, beautifully structured navigation, a modern overview, preset cards, improved search, streamlined controls and a redesigned quick-action area.
- Fully responsive light and dark modes, powered by the existing accent color and font size preferences.
- Keep the **201 existing settings**, favorites, reliable horizontal and vertical sidebar resizers, account data and secure Electron sandbox.
- Add a dedicated **Downloads folder** quick action.

## Downloading made simpler

- **Single-click Download video:** On an ordinary YouTube video, the main Download button immediately adds that video to Tubeium's download queue.
- **More options (⌄):** The adjacent chevron reveals Video, Audio, Thumbnail, full-playlist and Download Manager options without making the main button two-step.
- The download queue, chosen quality cap, FFmpeg handling, and original audio/video format preferences remain intact.

## Legacy uYouPlus download folder

- New downloads default to `Downloads/Tubeium`.
- A saved legacy download subfolder name is migrated to `Tubeium` on startup.
- If an old folder exists and `Tubeium` does **not** exist, it is renamed safely so the files remain available and known downloaded-file paths are remapped in the local queue.
- **No automatic merging or overwriting.** If both folders already exist, Tubeium preserves the old folder as-is to avoid losing files. An unrelated user-selected folder is never renamed.

## Known limitations

YouTube can change its page markup, sign-in acceptance, video formats and advertising behavior at any time. Ad skipping is best effort. Google sign-in and live 4K playback are not guaranteed. Automated source checks and Windows packaging do not replace testing in a real desktop session.

These EXEs are **unsigned** and may trigger a Windows SmartScreen warning. Download only from the official GitHub Releases page; verify checksums if desired, and do not disable your security software globally.
