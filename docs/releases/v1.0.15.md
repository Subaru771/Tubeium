# Tubeium v1.0.15 — Clean native YouTube fullscreen

**Windows x64 · unsigned installer and portable EXE**

## What changed
- YouTube fullscreen now shows **only the native YouTube player buttons**. Tubeium no longer overlays its top-right Download split button or the bottom floating Previous, Play, Next and Watch Later bar.
- Tubeium's extra Tools overlay, Quick Navigation, Shorts progress widget and secondary video actions are also suppressed in fullscreen.
- The fullscreen page never receives Tubeium action controls as new children, preventing duplicate or temporarily visible buttons when video layout changes.
- **Leaving fullscreen restores everything automatically**: Download on normal pages and the touch/mini-player toolbar when relevant.
- Playback, subtitle, quality, fullscreen exit, mouse, keyboard and touch support remain provided by the normal YouTube player while fullscreen.

## Verification
- [PR #29](https://github.com/Subaru771/Tubeium/pull/29) passed all 60 automated source regression test files, including fullscreen hide/exit behavior.
- The unsigned release workflow checks the dependency lock, runs the full source suite and audit, builds the Windows installer and portable EXE, and publishes SHA-256 checksums.
- Manual acceptance testing in a live YouTube fullscreen window on Windows, across touchscreen/desktop mode and YouTube layout variations, remains outstanding.

**Unsigned executables:** Windows SmartScreen may warn about an unknown publisher. Download only from the official releases page and verify checksums.
