# Tubeium v1.0.12 — Adaptive touch mode and cleaner playback

**Windows x64 · unsigned installer and portable EXE**

## Improvements
- Automatic touchscreen and pen detection: Windows tablets, 2-in-1s and hybrid PCs use larger touch targets and a responsive tablet layout. Connecting a mouse does not unexpectedly reset touch mode.
- Adaptive navigation in Settings, Downloads, Local Library, offline playback, Sign-in Help, and the Tubeium launcher, with large touch controls and scrollable compact navigation where needed.
- **Only Download stays below videos.** Additional Tubeium transport buttons are removed from YouTube's watch metadata action row.
- Previous, Play/Pause, Next, Watch Later and Tools remain available as an **in-player transport** for touch, mini-player and fullscreen modes. Watch Later remains reachable on desktop through the in-player hover toolbox and thumbnail actions.
- **Fullscreen Download fix:** the Download button is no longer hidden in fullscreen. It is positioned within the fullscreen player; format options open downward and Download still queues directly on the first click.
- Prevent duplicate player transport when YouTube replaces action rows during navigation.

## Existing features
Includes v1.0.11's offline playback queues, headphone/Windows media controls, Previous/Next behavior, and touch-friendly 44px controls, plus the earlier Download Manager and Watch Later improvements.

## Tests and limitations
Source CI passed on [PR #26](https://github.com/Subaru771/Tubeium/pull/26). The unsigned release workflow validates the dependency lockfile, runs the regression suite and security audit, builds the installer and portable executables, then publishes checksums.

**Not a phone app:** Tubeium remains a Windows desktop application. Touch mode adjusts the UI; it does not install on Android or iOS.

**Requires physical/manual validation:** real touchscreen and pen input, Windows hybrid behavior, fullscreen YouTube experiments, headset media keys, Bluetooth reconnection, Google sign-in, live YouTube videos and ad handling. Automated tests and successful packaging cannot guarantee these behaviors.

**Unsigned:** Windows SmartScreen may display an unknown-publisher warning. Download only from this repository and verify SHA-256 checksums.
