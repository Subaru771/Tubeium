# Tubeium v1.0.11 — Playback navigation and touchscreen controls

**Windows x64 · unsigned installer and portable EXE**

This update ships [PR #24](https://github.com/Subaru771/Tubeium/pull/24) and [PR #25](https://github.com/Subaru771/Tubeium/pull/25) on top of v1.0.10.

## New playback controls
- Previous, Play/Pause and Next in the video action area, including fullscreen and mini-player layouts.
- Next and Previous headphone/Windows Media Session commands use guarded navigation. Playlist and Shorts controls remain native; normal-video history is limited to 100 videos in memory, not written to disk.
- Touchscreen and stylus improvements: 44px targets, tap-open Tools, compact layouts for Settings/Downloads/Library, and scrollable native menu.
- Downloaded audio/video can play in an offline queue with Previous/Next, seek, optional autoplay-next, queue position, missing-file skipping and fullscreen support.
- Playback state, metadata and position supplied to Windows media controls for offline playback.

## Existing features
- Modern Download Manager with title, chosen quality, progress and pause/resume, plus reliability fixes from v1.0.10.
- Local Watch Later, playlists, cleaner Settings and the unified Tubeium menu.

## Verification and limitations
The merged PR #25 reports 57/57 source test files passing, successful automated touch/browser checks and a successful Windows installer/portable build. This release rebuilds both packages from the tagged v1.0.11 source after its own dependency, audit and test gates, and publishes SHA256SUMS.txt.

**Unsigned:** Windows SmartScreen may warn about an unfamiliar publisher. Download only from this repository and verify checksums.

**Not yet independently verified on physical Windows devices:** wired/Bluetooth headset buttons, device reconnection, lock-screen/minimized media controls, physical touchscreen/stylus behavior, live YouTube layouts, Google sign-in and ad behavior. These are not guaranteed to work in every configuration.
