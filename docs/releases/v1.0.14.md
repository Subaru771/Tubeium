# Tubeium v1.0.14 — Useful everyday improvements

**Windows x64 · unsigned installer and portable EXE**

## What's new
- **Touch feedback:** subtle indicators for double-tap seek, video/Shorts swipe navigation and video pinch zoom. Low, Normal and High touch sensitivity levels are saved on the device.
- **Memory monitor:** compare Electron working-set memory between two points in time, see process counts, and export a JSON report. Use Player > Memory monitor.
- **Open YouTube links in Tubeium:** opt-in Windows `tubeium://` protocol handler; copy a YouTube link and choose Player > Open YouTube link from clipboard. An optional Chrome/Edge/Brave extension adds context-menu actions; prepare it using Player > Prepare browser link extension, then load the folder manually in browser extensions.
- **Sleep timer:** 15, 30 or 60 minutes, or stop at the end of the current video. Available in Player > Sleep timer.
- **Transcript search:** search YouTube's rendered captions and jump to matching moments, with no transcription upload or account-data collection.
- **Chapter navigator:** filter and jump between chapters when the YouTube page makes the chapter list available.
- **Verified official installer downloads:** after a GitHub update is found, choose Download verified installer to stream the unsigned Windows installer, validate its SHA-256 hash against the exact GitHub release's checksum file, and reveal it for manual installation.

All video utilities are also in the Ctrl+K action search. No additional buttons are inserted below the video; Download remains separate.

## Security, signing and limitations
- Tubeium does **not** silently install or execute unsigned downloads. If checksum verification fails, the partial download is discarded.
- The existing signed Windows release workflow checks for release approval, a real signing certificate, verified signatures and matching updater metadata. **No signing certificate was provided**, so these release executables remain unsigned.
- Touch controls, transcripts, chapters, browser extension launching, Windows protocol registration, and RAM differences still require acceptance testing on real Windows devices. Some YouTube pages may not expose captions or chapters.
- The new memory tool reports working-set size, not promised RAM savings. Keep the video, quality, opened windows and other conditions comparable.
