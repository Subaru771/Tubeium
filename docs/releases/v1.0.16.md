# Tubeium v1.0.16 — Better touch and tablet controls

**Windows x64 · unsigned installer + portable EXE**

## Refined touch experience

- **No permanent video overlay.** Regular YouTube videos use native player controls rather than a floating Previous/Play/Next/Watch Later/Tools bar. The extra transport is available in Mini Player; fullscreen remains native-only.
- **Hybrid PCs change modes naturally.** Touch or pen activates touch-friendly spacing. Clicking with a mouse restores the compact desktop UI. Switching back is immediate.
- **Double-tap to seek ±10 seconds.** Left side rewinds and right side advances. If YouTube already performed the seek, Tubeium avoids adding another 10 seconds. Single taps are YouTube-controlled.
- **Swipe up/down for fullscreen.** A deliberate upward swipe on an ordinary video enters YouTube fullscreen; a downward swipe while fullscreen exits it.
- **Safer Shorts navigation.** Swipe up/down to change Shorts; Tubeium waits briefly for YouTube's native gesture first, then uses guarded navigation only if needed.
- **Better pinch zoom.** Zoom the video image from 1× to 2.5× around your fingers, restoring the original video transform on navigation.
- **Less accidental navigation.** Horizontal dragging across ordinary videos no longer changes videos. Touch gestures exclude menus, player buttons, the scrub bar and text inputs.
- **Easy fallback:** Player → Touch gestures → Off (YouTube only), Low, Normal or High. The selection is remembered. With Off, Tubeium does not suppress native touch panning.

## Checks and limitations

[PR #30](https://github.com/Subaru771/Tubeium/pull/30) passed the full 60-file source regression suite, including simulated hybrid mouse/touch switching, native double-tap seek avoidance, fullscreen swipes and zoom reset. The unsigned Windows release workflow independently checks dependency integrity and runs tests before packaging.

**Unverified on physical Windows hardware:** YouTube player layout variations, actual touchscreen input sequencing, pen behavior, hybrid tablet transitions, web-content scrolling, and live fullscreen gestures. Automated simulation cannot guarantee flawless input on every device.

**Unsigned:** The downloaded Windows executables are not code-signed; verify SHA-256 checksums from the official release page.
