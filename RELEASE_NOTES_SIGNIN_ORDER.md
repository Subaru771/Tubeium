# Tubeium v4.5.9 — Sign-in help order clarification

Only the instructions and their corresponding status messages have been reordered. There are **no changes to account handling, cookies, pairing, browser detection, players, downloads or settings**.

1. **Open Browser:** starts a fresh signed-out browser window.
2. **Open Extensions:** in the same clean browser profile, enable Developer mode, Load unpacked, and select the folder from Open Extensions Folder.
3. **Sign in & transfer:** return to the YouTube tab in that browser, sign in, then use the Tubeium extension. Paste the copied pairing code if needed. Tubeium restarts after a successful import.

The clean session remains separate from normal browser profiles, and a sign-in transfer is not guaranteed to be accepted by Google.
