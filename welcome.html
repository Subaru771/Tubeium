SIGN-IN HELP

Sign in to Tubeium

First, try signing in normally

Click Go to YouTube and try signing in. If Google blocks it, come back here and start with Open Browser.

↗
IF THE NORMAL SIGN-IN FAILS

Use the browser extension

  1. Open a clean browser

    Click Open Browser. YouTube opens in a new browser window with no account signed in. Keep that window open for the next step.

  2. Install the extension in that browser

    In the clean browser window, open the Extensions page (Brave: brave://extensions, Chrome: chrome://extensions, Edge: edge://extensions). Enable Developer mode, click Load unpacked, then click Open Extensions Folder below and select that folder.

  3. Sign in and transfer

    Go back to the YouTube tab in that browser and sign in. Click the Extensions (puzzle-piece) icon, open Tubeium, then click Transfer sign-in. The code is copied automatically; press Ctrl+V if the code box is empty. Tubeium will restart automatically after a successful import.

Important: This uses a separate, temporary Chromium browser profile, not your usual signed-in browser. If your default browser cannot run the extension, Tubeium will explain which compatible browser it opened instead. Close the temporary browser when finished; importing cookies does not guarantee Google will accept your session.

Only transfer a session from your own account. Login cookies are sensitive and stay on this computer during the transfer. You can remove the extension after signing in.
